# Optional target contrasts and state-priority updates

The ordinary field predictor can compare saved physical fields from several real scenes at aligned physical positions. A target describes a requested finite input modification; a coefficient row combines errors on those existing scenes. This does not label a virtual edited scene or supply an independent physical solution. Native training remains available without either option.

`honf_runtime.response_targets.ResponseTargetAdapter` supplies complete inputs, legal before/after descriptions, an input chart and aligned observations. The case adapter owns geometry legality, derived controls, units, gauges, precision and physical support. The shared CPU FP64 solver minimizes normalized RBF discrepancy plus coefficient dispersion with zero-sum coefficients and L1 at most two. Its relative discrepancy describes approximation in the specified function class, without a physical-error guarantee. An unresolved target returns an explicit unsupported result.

`WeightedResponseContrast` accepts an arbitrary number of scene-coefficient rows and explicit nonnegative row weights. `neighborhood_field_losses` sums their squared residual combinations with those weights and the supplied channel weights, scales and fixed physical masses, then averages prediction views. The existing `LocalContrast` reduction is unchanged. A one-row target uses row weight one. A strength-matched uniform loss uses `q = ||a||² / 2`; scaling its operator uses `sqrt(q)`. Zero response rows retain all scene predictions and absolute observations.

The Thermal local-response adapter accepts `targeted_reynolds_response` and `trace_matched_uniform_response`, with saved `target_definitions` alongside its existing `input_definitions`. The Reynolds pilot preserves geometry and every member's source, changes Reynolds number by ten within the declared observed range, and updates derived viscosity consistently. Modified input descriptions explicitly mark their physical reference unavailable; copied source runtime metadata does not assert that the modification was solved. Only eligible original-deck centers receive a response penalty; the native membership, absolute labels, original common-fluid mask and seeded episode schedule remain intact. The target-definition file is small prescribed-input metadata, not a field dataset.

Set `thermal_local_response.state_priority` to true to protect the aggregate gradient of the native objective and additional absolute fields. The generic trainer identifies response terms through `provider.state_priority_response_terms`. It obtains response gradients from the same prediction graph, adds the absolute gradients to the accumulated native gradients, applies the provider's gradient hook, and removes any response component opposing that complete state gradient. Projection precedes the existing global clipping and optimizer update. State norm at most 1e-12 suppresses the response; parameters unused by both terms keep a missing gradient. Updates without an auxiliary episode use the ordinary native path.

This operation is a Euclidean gradient projection. It does not preserve an AdamW displacement, individual state losses or held-out physical accuracy. Separate backward traversals can recompute checkpointed activations. The recorded total TRAIN loss is a nominal monitoring sum, not a scalar objective whose gradient equals the projected update; full local-response validation loss is unmeasured, so curves label the measured native-only subtotal.

State-priority history columns record sums and their explicit active or defined counts. Divide cosine sum by cosine count, and retained response fraction sum by its defined count; never divide these by all native updates. Absence, zero response, suppressed state and non-conflicting active episodes have separate counts. At declared review ages, a sampled state-gradient dot actual parameter displacement includes AdamW weight decay.

Fresh-process recovery uses the run's saved ordered recording definitions, model, optimizer, RNG and provider state. Initializing a new child from a literal native age-ten snapshot preserves its historical rows and native loss order. Ordinary resume validates scientific definitions without rewriting logs. The focused tests cover weighted row arithmetic, projection, checkpointed graphs and actual save/reload/append; physical usefulness still requires the declared matched learning comparison.

# HONF next phase: native-context organizer confirmation

## 0. Decision and scientific question

**Do not launch the current Tree900 as the project's definitive 5,000-epoch HONF model. Do not resume the same three-term Tree simply to obtain another large epoch count.** Preserve it as a matured research result and retain its successful execution repairs.

Conduct one matched Thermal development experiment:

> When a capable multiscale physical backbone is held intact, does receiver-dependent hypergraph organization provide something that a competent case-global collective controller does not?

Implement and train two models, **Tree-C** and **Global-C**, on fixed25_v1. Both use the existing native coarse/local context, source-local input semantics, fine source-resolved interactions, and the same physical heads. Tree-C adds the current measure-consistent adaptive receiver organization. Global-C uses one openly declared, case-global collective control per mechanism, without learned receiver partitioning or source omission. Global-C is an explanatory control, not a proposed adaptive-K HONF success.

This choice addresses a confound in the completed experiments: the strongest Dense model retained coarse and local context while Tree, Pair, and Fine removed those pathways. It also addresses a second ambiguity: Tree's useful controls could largely be doing global route calibration rather than identifying useful receiver-specific interactions.

The two alternatives must actually learn. A numerical audit, nonzero gradient, or successful startup is not completion of this plan.

The primary destination is **500 development epochs per arm**, after an actual e100 review. A paired extension to **1,000 total epochs per arm** is available after e500 if it fits the resource allowance and answers an unresolved learning question. No new inverse generator, design-search campaign, Wind training, physical-reference solve, full-data run, or automatic formal launch is included.

Restoring context is a proposed hypothesis, not a source-supported explanation of all error. Adding coarse/local context does not prove early pooling caused the earlier deficit. Fine physical values were already retained. The new comparison asks whether organization helps when those additional physical representation paths are present.

## 5. Mathematical design: one backbone, two organizing hypotheses

Let d contain module geometry/material descriptors, c prescribed context, a the module source amplitudes, and x a receiver. Each phase has encoded module states z^M, raw environmental states z^E, physical source measures and a prescribed global token g.

Both new models retain the native multiscale construction conceptually as

\[
\widehat y(x)=D_{\mathrm{native}}\bigl(x,g,
 C_{\mathrm{coarse}}(x)+C_{\mathrm{local}}(x)
 +C_M(x)+C_E(x)\bigr).
\]

This is a conceptual decomposition. Reuse the exact existing `SharedInterfaceContext` preparation, local read, field-head inputs and assembly rather than replacing its implementation with an assumed formula. Preserve the native choice of which phase-current source states feed the coarse and local paths.

The coarse latent route is a supplemental global summary. The local route is a supplemental near-source correction. Neither replaces the original nonlinear fine source reads. Therefore, adding these paths is not a return to using early pooled source values as the only physical representation.

### 5.1 Tree-C: receiver-dependent collective control

Retain the current canonical measure index, weighted geometry, typed donor inventories, direct fine values, and adaptive frontier. For route tau define receiver access A_re, source membership B_es and group control h_e. On eligible pairs,

\[
\rho_{rs}=\sum_e A_{re}B_{es},\qquad
\bar\rho_r=\frac{\sum_s\mu_s\rho_{rs}}{\sum_s\mu_s},\qquad
w_{rs}=\rho_{rs}/\bar\rho_r.
\]

Use the current empty-row conventions, masks and source measures. Group controls retain both declared donor types:

\[
h_{e,\tau}=H_\tau(\bar z^M_{e,\tau},\bar z^E_{e,\tau},
\gamma_{e,\tau},g,\mathrm{phase}).
\]

The rich all-source planning descriptor stays out of h's content input. Memberships may still depend on all current source states through planning. This distinction is explicit, not hidden by a sparse picture.

For ordinary message routes, use the existing fine message m_rs and projected collective modulation:

\[
\widetilde m_{rs}=w_{rs}\,[1+\tanh(\ell_{rs})]m_{rs},
\quad
\ell_{rs}=b_\tau+
 \frac{\sum_e A_{re}B_{es}W_\tau h_e}{\rho_{rs}}.
\]

For QE, retain the source-measure prior, one attention normalization over the unique supported physical sources, projected score offset and projected value gain. Do not create one separately normalized physical attention per group or count a duplicated source several times.

Use the already implemented projected actions and local-context organizer shadow. Do not restore the second whole physical wrapper. No large receiver-by-source-by-control-dimension tensor belongs in the routine numerical path.

Tree-C is allowed to learn full support or a constant frontier. Report that outcome honestly. Do not impose a K histogram, a target source percentage or a maximum-field-error reward that silently sacrifices thermal/flow quantities. Retain the current bounded proposal capacity; it is not the realized number of physical interactions.

### 5.2 Global-C: competent global collective control

Global-C has the same native context, physical fine kernels, heads and source-local feature conventions. It retains full eligible fine access, w_rs=1. For each mechanism and phase, form one case-global control from the measure-weighted module/environment summaries, prescribed context, receiver-role/domain geometry and source-presence statistics:

\[
h_{\tau}^{\mathrm{global}}=
H_\tau(\bar z^M,\bar z^E,\gamma_{\tau}^{\mathrm{global}},g,\mathrm{phase}).
\]

Broadcast its projected gain to the relevant fine read. A source-independent QE score offset cancels from softmax exactly; keep that redundant offset zero/non-trainable rather than claiming it is a useful learned control. Tree-C retains its genuinely source/receiver-dependent QE score channel. Global-C has no learned receiver partition, no source-scoring mask and no adaptive-K claim. The control-head width/depth and gain parameterization should match Tree-C wherever meaningful. It does not need dormant Tree tensors to pad its parameter count.

Why this control: the current Tree's supported QM gain RMS is approximately 1.999, near the parameterization's upper limit of 2, while QE's gain RMS is about 0.334. These measurements motivate testing global route calibration against spatial organization. They do not prove that all Tree controls are constant or useless.

If Global-C matches Tree-C after training, collective conditioning may be useful without the particular receiver partition. If Tree-C adds consistent role/response value beyond Global-C, that is stronger evidence for organized interactions than an identity ablation alone. Global-C specifically controls for case-global calibration, not every possible nongraph architecture. The earlier Pair result remains separately labelled; superiority over all nongraph models is not claimed.

Start control projections at zero and source densities at unit/full access. Keep the established nonzero group-control output bias that allows the initially zero gain projection to receive a task gradient; do not accidentally initialize both multiplicative sides to zero and create a dead adapter.

Not every organizer tensor receives a task gradient at the first identity-initialized step. Test useful gradient propagation after a few real updates, once the initially zero projection has learned; do not turn its deliberately staged initialization into a false startup failure.

## 10. Formal-run decision and exit criteria

Do not require HONF to beat Dense on every scalar, to be the fastest kernel, or to solve generative inverse design before any formal learning experiment. A formal run is a scaling/generalization experiment, not a production safety certificate.

However, the current Tree900 should not be promoted merely because it trained for 1,000 epochs. The next recommendation must address:

1. **A credible prediction tradeoff:** a clear advantage or acceptable compromise on the task-relevant roles, without hiding flow/high-M/interface tails in one aggregate.
2. **A reason to retain organization:** evidence beyond identity ablation that the trained receiver-dependent model offers value over the trained Global-C control, or a clearly stated still-unresolved hypothesis for the proposed formal comparison.
3. **An understandable implementation:** equivalent-representation discrepancies and state-restoration failures have been corrected or localized and quantitatively bounded, rather than simply relabelled as passes.
4. **An honest inverse-readiness boundary:** cheap input/response behavior is usable; held positive-response truth and physical design validity are separately unavailable unless measured.

Outcome classes:

- **Recommend a manual full-data comparative run:** the pair provides a meaningful organizing hypothesis and a viable predictor; prepare Tree-C plus the appropriate nongroup control. Describe exactly what full-data training would test.
- **Recommend a strong nongroup forward foundation, not HONF confirmation:** Global-C/native context explains the useful accuracy and Tree adds no measured value. Do not keep launching Tree variants solely to obtain a preferred outcome.
- **One localized unresolved implementation issue:** deliver its reproduction and the completed learning evidence; do not turn this into another large diagnostic portfolio.
- **Resource-censored:** state exact completed ages and what remains. Never call an uncompleted training target successful.

A 5,000-epoch recipe must be a separately labelled **fresh full-data training configuration**, with original training membership, its own training-only normalization and absolute formal schedule. Do not silently resume a quarter-data checkpoint across membership/normalization changes. Preserve historical mature Run1804 as context, not a matched fresh control.

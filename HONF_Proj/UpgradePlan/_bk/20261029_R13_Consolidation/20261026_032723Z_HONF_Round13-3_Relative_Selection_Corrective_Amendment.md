## Failure to reproduce and distinguish

The old proposal and member distributions each append a fixed-zero null. The member scores additionally include `log(pi B) + log(nu)`. A common score offset or common prior scale can therefore change all relative rankings into an all-null decision. In that exact-zero region the native task has zero local selection derivatives, while the query-conditioned output head still learns. Saved Route histories establish that E reads disappear after epoch 1 and M reads after epoch 2; they do not uniquely identify the initiating feature/key drift. The corrective native replay records raw scores, offsets/spreads, priors, effective scores, actual applied B, gradients and fixed-query heat sensitivity from the current saved checkpoints. Same-checkpoint offset interventions preserve ranking, candidate IDs and B; reopening a path is an arithmetic diagnostic, not recovered physical fidelity.

## One proposed candidate, written before implementation

Use a new `interaction_reused_member_routing_v2` capability, named `R13-3-Relative`, without changing v1 loading or resuming the failed Route weights. Retain the original-record keys, values, pair-score MLPs, actual applied final MM/ME gates, M identity access and declared M/E measures. Normalize query/key feature blocks for routing only; values and the physical input records retain their original contents. For a candidate-masked score row define a relative score `N(r) = 4 tanh((r - mean_C(r)) / (4 sqrt(var_C(r) + 1^2)))`. This removes a common offset and controls spread. The unit numerical floor uses population variance and bounds the centered-score gain at ties instead of amplifying near-tied gradients by a small inverse epsilon. It deliberately avoids an undefined scale/derivative at ties; it does not promise exact invariance to arbitrary feature changes or rescaling at a flat row.

For present M addresses, use conditional relative probabilities with no proposal null: `pi_q = softmax(N(g_q) / T)`. When M is absent, pi and both contexts are zero. This is a distribution conditional on taking a read, not a compulsory value read. Compose the same live actual applied directory: `a_t(q,i) = sum_m pi(q,m) B_t(m,i)` and `C_t(q) = {i: a_t(q,i)>0, present and physically eligible}`. Exclude zero-measure/ineligible records and branch to zero context before logarithms when no candidate exists. Normalize the information prior within each type, `P_t(q,i) = a_t(q,i) nu_t(i) / sum_{j in C_t} a_t(q,j) nu_t(j)`, evaluate its normalized logarithm as `log(a)+log(nu)-logsumexp(log(a)+log(nu))` to avoid a premature probability underflow, then compute `p_t(q) = softmax((N(f_t(q,i)) + log P_t(q,i)) / T)` on C_t. Common score offsets and common within-type prior scales cannot become evidence of irrelevance. M1 has no relative address choice; zero address-ranking gradient there is expected, not failed learning.

Learn read necessity separately. A small typed network receives the normalized query and two relative selection statistics (the p-weighted normalized score and normalized entropy), where the entropy is `H(p)/log|C|` for more than one candidate and zero for a singleton, and emits a learned read/skip contrast `d_t = u_read - u_skip`. It receives no unrestricted original values or raw controls. Use the smooth probability `rho_t = (1 + d_t / sqrt(1+d_t^2))/2`, evaluated with its stable rational form in the tails. Its mathematical derivative is `1 / (2 (1+d_t^2)^(3/2))`, positive for finite real d_t, including an unhelpfully closed early read. Actual native recovery also requires a nonzero downstream `dL/drho`; both quantities are observed. Saturated or extremely skewed priors can still yield numerically unrepresentable gradients in finite precision; no universal recovery guarantee is made. This is a learned access strength, not a calibrated physical-necessity probability. Set rho to zero for a genuinely empty type. The continuous training weights are `w_t(q,i) = rho_t(q) p_t(q,i)`, typed null mass is `1-rho_t`, and `c_t(q) = sum_i w_t(q,i) V_t(z_i)`. Only `[q,c_M,c_E]` enters the existing joint trunk/head; there is no pooled replacement or independent value branch.

Finite eligible member logits have continuous softmax feedback in training. Actual B zeros remain the historical contextual hard-gate boundary: there is no fabricated decoder access or claimed local gradient through a zero B edge. Such an edge can change only through other live contextual/feature paths; recovery is not guaranteed. A whole missing information path remains actionable. These limitations, finite-precision underflow and legitimate per-query/type omission are observed explicitly rather than hidden behind an initialization test.

## Training versus the sparse executor

Training evaluates all organization-eligible original member values, with the continuous weights above; it therefore makes no sparse-training claim. Sparse evaluation sorts those weights, with stable original-ID tie handling, and keeps the shortest prefix whose omitted absolute real mass is at most `eta=0.01` per query/type. Retained weights are not renormalized; dropped mass goes to the zero context. A type can execute no values when its learned real mass is at most eta. This is an explicit approximation budget, not fixed K, a quota, a compulsory M/E winner or a fidelity admission policy. The continuous context error is bounded by `omitted_mass * max_i ||V_i||`; combine the two typed bounds in Euclidean norm for the joint context. Physical output error after the nonlinear head is measured, not inferred from that bound. Report continuous-reference versus sparse fields, responses, original IDs, candidate scoring, indexing/sorting, projections, selected/executed values, full call/backward costs and memory. Broad B/candidate scoring can still defeat efficiency. The old instrumented timing did not establish pair-MLP kernels alone as the bottleneck, so the first repair does not replace that architecture or introduce a geometry shortcut.

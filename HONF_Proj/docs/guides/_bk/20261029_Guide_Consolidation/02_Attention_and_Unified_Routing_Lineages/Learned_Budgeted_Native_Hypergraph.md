# Learned budgeted native hypergraph

**Archived reference — 29 October 2026.** This guide records a predecessor model or a dated experiment, not current architecture policy or standing launch authorization. Use the [current guide index](../../../README.md); see the [archive review](../README.md) for the reason it was moved.

Round8 is a separately versioned A2-D continuation family, `native_budgeted_dispatch_v2`. It learns one shared binary member list for each present native module seed and dispatches each query to one seed. The decoder evaluates the original nonlinear value of every retained query–module pair. A list contains indices into original contextualized records; it is not a pooled decoder value. The existing contextualizer, local branch, native transforms and signed Thermal heat law remain with A2-D.

Round7 remains available under its original family, loaders, thresholds and launch gate. Its negative admission receipt is historical evidence and is never converted into Round8 authorization. Research correctness, learned field/work quality and complete-call acceleration are separate decisions.

## Field and routing contracts

Preparation captures the final-cycle MM raw scores before donor log measure. A convex head mixture, one bounded positive scale and one scalar bias define shared module-membership logits. Self membership is one; absent records are excluded. Physical record presence remains distinct from positive information measure. The primary consumer is M-only: E influences original contextualization, but there is no direct E decoder, E gate parameter or direct E saving.

Queries reuse the original decoder scores, with a separate convex head mixture and bounded scale, to dispatch one native seed. Deterministic score ties use input geometry and characteristic lengths. Geometrically indistinguishable tied maxima are reported as indeterminate and rejected by the primary executor; an ID never breaks a physical score tie. IDs only label correspondence and reproducible routing noise.

The final support is the dispatched seed's binary membership unioned with the original input-defined direct local protection. The same original nonlocal value function evaluates protection exceptions. The original smooth local branch remains separate, and neither its radius nor its weights are expanded to compensate for source omission. Every surviving nonlocal Thermal coefficient keeps its full signed amplitude; attention normalization is confined to the information path.

## Learning and work

The exact D0 e500 source supplies original parameters, nonzero named AdamW moments, TRAIN-only normalization, dataset membership, native losses, source query streams and absolute schedule. A new named optimizer group contains only the small route-calibration parameters, uses the inherited learning-rate schedule and has zero weight decay. The new model also persists phase, temperatures, dual variables, noise identity and macro-step clocks.

Birth membership is calibrated once on at most eight fixed TRAIN input batches to approximately .98 expected valid nonself membership. A separate TRAIN-only gradient calibration sets `lambda0` so its initial router work-gradient norm is approximately one tenth of the native router task-gradient norm. The recipe records the actual scalar values; defaults are not calibration evidence. No DEV error, target field or current heat enters input-only birth calibration or the deployed router.

For unit logistic member noise and unit Gumbel categorical dispatch noise, expected unique support is `P + (1-P) * (pi @ p)`. Count rows, not attention mass or physical quadrature measure. Aggregate query tiles and native roles within each case before taking equal-case means. The target count is `max(1, |P|) + rho * (M - max(1, |P|))` for a nonempty scene. A separate scheduled response request is counted explicitly. The augmented constraint applies to the complete optimizer macro-batch's mean residual, not a mean of independently hinged case penalties.

At e501–700 every update uses dense original values with a binary hard-forward routing estimator. The multiplicative information normalizer retains a derivative with respect to an omitted zero gate. Its backward is a biased relaxation, not the derivative of a discrete inference decision. The value-path derivative is multiplied by the hard gate. After e700, every fourth global macro-step restores dense omitted-value task signals; other steps use fixed-support physical gradients and the differentiable work objective. Stochastic noise reaches zero at e1500, and e1501–2500 uses deterministic hard forwards. Later sigmoid/softmax work is labelled a relaxation; dual feedback uses observed deterministic work after e700.

The dual updates every ten successful optimizer macro-steps. Native supervised losses, the work penalty, relaxed work, observed hard work and execution counters are recorded separately. A lower combined loss cannot establish physical-field preservation. Terminal support is measured at its declared threshold; evaluation never forces a top-K to repair a missed budget.

## Execution and numerical evidence

`dense_hard_reference` independently computes the full original native values and applies the binary selected reduction. Dense routing-gradient steps deliberately evaluate omitted values and count that work. `flat_selected_reference` evaluates admitted unique pairs. `grouped_native` packs queries by scene and seed and evaluates rectangular query/member blocks, including protected exceptions with one final normalization. Padding, invalid rows, compaction, synchronization and all native role calls are charged. A grouped backend that does more padded work than a flat reader has not earned a sparse-execution saving.

The dense reference is checked against an independent FP64 literal native-token loop, including fixed-support VJPs. Selected/grouped backends are compared at identical binary masks. Original all-open A2-D recovery, strict legacy FP32 status, new research engineering guardrails and native physical-reference error remain separate measurements. A failed grouped qualification selects the correct research reference; it does not erase or cancel affordable scientific learning.

Prepared stores and sampled graphs bind model ownership, weight/buffer versions, scene geometry, native IDs, measures, frame, normalizer and configuration. Public boundaries reject stale or mutated state and reuse after backward consumption. One prepared scene supplies one membership sample across its query chunks. Exported inference geometry derivatives use the fixed hard route; they do not include the training router estimator or a derivative through a changed dispatch.

## Bounded continuation and interpretation

The authorized development comparison comprises Thermal D8/G8 and Wind D8/G8 from exact D0 e500 through absolute e2500, with reviews at e600/e1000/e1500 and scientific checkpoints every100 epochs. Original effective/micro batches, partial final updates, native queries, response cadence and exposed DEV boards remain fixed. Literal e2500 results are primary; best-field aliases are secondary and use the same declared monitor. Full history, ten-epoch loss curves and visible progress remain enabled.

Launch requires a separate Round8 research receipt covering source identity, original boundary recovery, the dense mathematical reference, useful routing gradients, heat/target isolation, real-objective optimizer memory and reserved resources. A `not_faster` startup measurement is permitted. Resource exhaustion, unresolved semantic/nonfinite failure, the plan's persistent catastrophic divergence criterion or an explicit user stop can end a continuation at a resumable boundary. Initial dense support and poor optional-backend speed cannot cancel an otherwise qualified comparison.

Complete host-input/native-CPU-output latency, prepared-scene/new-query reuse, fixed-query/new-heat reuse and complete native training steps have different amortization scopes. Report each against the unchanged original A2-D denominator with matched hardware, precision, output scope and fair tiling. Logical sparsity, actual executed rows, memory and complete latency are distinct outcomes.

This family does not authorize full-TRAIN fitting, inverse optimization, new reference solves, a second dispatched seed, a pooled bank, an extra utility network or a direct E consumer. Thermal heat algebra is checked separately from ordinary FP32 endpoint cancellation and saved physical-response fidelity. Learned support is executed model information flow, not physical causality; fixed-support geometry autodiff is not inverse-design readiness.

## Reopening checkpoints and traces

`tools/native_budgeted_train.py` seals recipes, performs CPU preflight and launches only admitted segmented continuations. Its `fit --dry-run --device cpu --recipe <recipe>` validates the saved contract without a provider, optimizer or run output; it is not a completed learning step. Actual `fit` requires the exact research receipt, reserved output root, explicit `--yes`, physical GPU2 mapping and a declared absolute review stop. Resumption restores full named optimizer, RNG and sampler state rather than treating a weight file as a new initialization.

Use `tools/content_hypergraph_evaluate.py` to reopen a literal checkpoint. The Round8 Wind source-TRAIN native panel contains 6,144 volume plus 2,048 hub-band queries, with 0.75/0.25 weights; exposed DEV contains 8,192 plus 2,048 queries, with 0.8/0.2 weights. TRAIN audit scores use a separate namespace and are not DEV selectors. The five-role physical audit is a separately declared posthoc panel, not a replacement for either original objective. Check saved and loaded absolute age, cumulative macro clocks, source/provider identities and checkpoint hashes before interpreting endpoint fields.

Decoder trace names belong on `core.decode(..., trace_request=...)`. The maintained Wind provider's `trace_request` argument forwards preparation traces; passing decoder-only names there does not measure a value read. Keep trace payloads bounded, request the specific fields needed, and use fresh preparation when changing a backend or support override. A complete-call timing must disable diagnostic traces and retain the same host/native-output boundary for its control.

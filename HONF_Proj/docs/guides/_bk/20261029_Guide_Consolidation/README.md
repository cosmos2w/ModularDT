# Guide consolidation review — 29 October 2026

All 49 former top-level guides were inspected for their model family, recipe/authorization scope, current code interfaces and repository references. Five remain as everyday references; 44 are retained below in three thematic groups. This is a documentation relocation only: historical model code, configuration/checkpoint identities, numerical evidence and training jobs are unchanged. Archive dates describe this review, not experiment completion.

Existing relative links were rebased to the same intended files, and references from other maintained documents were redirected. Historical prose and commands remain historical; explicit archive notices prevent old launch permissions or specialized output laws from being mistaken for current instructions. The complete current entry point is [the guide index](../../README.md).

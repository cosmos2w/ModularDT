# Inherited attention: IAG-C and conditional IAG-Q

IAG-C replaces the distant query/source pair-value decoder with reusable values at the existing environment anchors. It retains the ordered MM → EM → EE → ME contextualizer, width 128, four heads, two cycles, raw/scene reinjection, native physical extraction and the bounded local reader. It is a separate `inherited_attention_core_v1` family; historical A2-D, H6 and source-read checkpoint constructors keep their own schemas.

The final cycle exports the live EM and EE normalized Q/K ingredients, bounded temperatures, additive geometry scores, masks, physical measures and native correspondence IDs. EM scores describe environment receivers reading modules after MM; EE scores describe environment states after EM. Payload projections use final contextualized token states, including subsequent ME/FFN updates. Exporting scores does not replace fused contextualization or imply that score-origin states are final payload states.

## Mathematical and execution boundary

For each physical donor type, an atlas has shape `[B,H,E,N]`, final projected token values have shape `[B,H,N,32]`, and scene preparation computes `G = P @ V` with shape `[B,H,E,32]`. Each native query supplies a `ReceiverCover` containing four Thermal or eight Wind anchor indices/IDs and continuous partition weights. Ordinary decoding gathers only these indexed anchors, then combines the two typed contexts. It never constructs a distant query/source 128-wide value tensor or an ordinary dense query/source coefficient cache.

The native adapters construct C1 tensor-product smoothstep covers from actual E192/E64 coordinates and map each corner to the original environment token ID. Edge extension is constant inside the adapter-declared legal domain. Wind carries the authoritative native lower/upper bounds in an `InheritedSceneBatch`, separately from the unchanged coordinate origin/extent used by contextualization; reconstructing an upper bound from rounded FP32 origin plus extent can exclude valid boundary receivers. Queries outside the authoritative domain are rejected. Derivatives flatten at anchor planes; this is an explicit approximation limit. The core accepts any valid bounded cover, including a non-lattice cover supplied by another geometry owner.

Thermal keeps heat-independent u/v/p and source carriers `[B,H,M,8]`. Its response uses `P_module / normalized_module_measure`, contracts carriers with heating at scene anchors, gathers the anchor response and contracts with heat-independent query factors. The native temperature scale is applied once, with no temperature mean. Zero heating gives zero temperature. Native curl and the maintained normal-flux proxy retain their existing extraction. The reverse contractions implement the heat adjoint; explicit dense K export is a bounded diagnostic entry point only. Wind retains its TRAIN-fitted height profile plus scaled residual without adding an absolute-velocity mean or another frame rotation.

Soft normalization is proportional to physical measure times exponentiated inherited score. The sparse child uses the measure-relative 1.5 law `p_i = m_i * relu((s_i - tau)/2)^2`, with unit row mass, typed masks and exact empty zeros. Its vectorized sorted-prefix solve retains score and normalized-measure derivatives; an independent FP64 bisection provides the reference. There is no utility scorer, completion branch, teacher refresh, sparsity penalty, fixed six-content bank or hidden distant correction.

`scene_executor=dense|selected` compares a dense contraction with actual positive-edge indexed contraction of the same probabilities. `query_executor=indexed|dense_reference` compares indexed cover reads with a literal dense cover of the same function. Every positive blend entry executes; zeros alone are not evidence of acceleration. Contextualizer work remains full access. Work counters distinguish eligible associations, positive support, executed scene edges, cover slots, local rows and native receiver unions.

## Diagnosed query-conditioned replacement

IAG-Q is the single permitted Wind replacement after a documented fixed-weight TRAIN diagnosis shows loss of within-region wake detail. The current implementation enables it for Wind only; Thermal retains IAG-C and its source-indexed affine interface. A scientific Q start requires the measured representation-review receipt, fresh weights and an empty optimizer. It cannot resume IAG-C weights under a new label or branch from a C parent. Width, depth, environment catalogue, objectives, native queries and initialization/sampling conventions stay unchanged.

For each type, Q retains the inherited atlas and final token values but replaces the cached `P @ V` aggregate with `w(q) @ V`, where `beta(q) = Lambda(q) @ P` and `w_i(q) = beta_i(q) exp(score_i(q)) / sum_j beta_j(q) exp(score_j(q))`. The query encoding and final token states pass through the same live final EM/EE query/key LayerNorms, projections, L2 normalization and bounded head temperatures used by the contextualizer. These modules are registered once; there are no additional learned parameters or pairwise geometry/value networks. Exact-zero beta stays excluded, including under sparse normalization, and empty typed rows return zero.

`scene_executor=cached_tokens` records that Q projects final token K/V once and does not compute scene `P @ V`. `query_executor=cell_selected` groups queries by their complete input-only cover-anchor signature, builds one positive donor union per structural cell across heads, and gathers K/V once per cell. Batched scalar-attention matrix products then share those operands across the cell's receivers. There is no query/donor/128-wide message tensor. One geometry grouping/sort is charged per request, and all padded query/candidate products are reported; this grouping never pools query features or uses targets. `dense_reference` evaluates the identical beta-weighted scalar attention over the complete donor axis as a correctness and cost control. Both typed contexts feed the existing fusion, local reader and field head.

The Q child inherits only its own literal soft e500 state and representation-review identity. Its cached-token/cell executor stays fixed while decoder normalization follows the same e501–800 transition. Its full-TRAIN recipe is still inert until literal e2500 qualification and a current resource budget permit one fresh hard-e1000 probe. Q may recover discrimination at extra query work; its actual latency, padding and memory determine whether that tradeoff is useful.

## Protocol and lineage

Recipes are under `src/config_core/forward/inherited_attention/`. Development uses Round3's exact fixed TRAIN150/DEV22 Thermal and TRAIN72/DEV24 Wind identities and TRAIN-only transforms. Thermal retains Q1024, effective batch48/micro24 and the native auxiliary/response objective. Wind retains Q8192 split6144 volume/2048 hub band, effective batch16/micro8 and the standardized equal-component 0.75/0.25 objective. Both use constant all-parameter AdamW 3e-4, weight decay1e-5, clipping1 and deterministic case/epoch sampling. Wind's omitted TRAIN M18 stratum remains a limitation. The shared `fp32_deterministic_cuda_v1` numerical policy sets CUBLAS workspace `:4096:8`, enables strict deterministic algorithms, disables TF32 and cuDNN benchmarking, and leaves SDPA backend availability unchanged. Current D0/candidate timing comparisons apply the same policy; historical D0 training is preserved under its original policy.

A fresh soft model starts with fresh weights and optimizer. Common named parameters are initialized identically to D0; new heads have deterministic name-based initialization. Reviews use saved weights at100/500/1000 and a healthy trajectory may mature to2500. A sparse child branches only from its own chosen soft model's exact e500 checkpoint, preserving weights, Adam moments, RNG, provider state and history. It begins at absolute501, uses `(epoch-500)/300` blend through800, and is fully sparse from801. Parent-prefix exposure is counted once. Primary qualification uses literal2500. For secondary selected soft/sparse comparisons, both arms use the lowest declared monitoring field metric over saved ages600–2500 (earliest tie), with their common500 state shown separately. The engine's original latest/best aliases and their selection domains are retained; no later native-board or response error selects weights.

The measure-entmax solver computes prefix moments and thresholds in FP64, selects the largest active prefix, and returns probabilities in the input dtype. This repairs rounded FP32 interval gaps at support boundaries without changing the measure law or soft normalization. An old-source soft e500 parent requires an explicit `--normalization-correction` receipt for attachment to the corrected runtime: exact checkpoint, recipe and loaded-source hashes are checked, with fixed file allowlists and no ordinary-resume source override. Thermal's earlier source also requires bitwise soft native-output and named-gradient equivalence on the fixed TRAIN M1/4/7/12 panel before accepting its inactive Q-support additions. The correction binding persists in the child; subsequent resume must match its exact corrected source. Failed attempts and their partial work remain separate evidence.

Prepared scene and affine-query caches validate owner, parameter/buffer versions, scene/frame/normalizer identity, cover/query IDs and tensor mutations. Reusing a consumed training graph is rejected. All prepared scene/query factors require versioned tensors; use `torch.no_grad()` for inference. The core rejects inference mode because its tensors do not provide PyTorch mutation counters. Execution-policy or normalization-state changes require fresh preparation.

The separate `inherited_attention_full_train1000_v1` protocol requires a measured qualifying literal e2500 candidate and an explicit remaining-budget receipt before allocation. It uses fresh full-TRAIN transforms, weights and optimizer. It has a hard1000 endpoint and rejects5000. A fresh sparse full-TRAIN probe is soft through500 and blends501–800, so only its last200 epochs use the exact sparse law. Development identity cannot silently resume into full training. Historical H6 and formal-D authorization remains separate.

Validation cadence and selection stay protocol-defined. Full history, latest/best-field aliases and declared100-epoch milestones are retained; loss curves refresh every10 epochs. Separate validation files are written only at milestones and final/clean-stop reviews. tqdm remains enabled by default, including tmux and redirected output. All training/evaluation must use the separately authorized physical devices and verified shared caches, preserve holdout locks and keep solver usage326/326.

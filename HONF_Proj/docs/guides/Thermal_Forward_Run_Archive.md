# Thermal forward-run archive

On 23 October 2026, historical Thermal forward runs were grouped beneath `Trained_Results/ThermalChannel/HONF_Forward_Runs/bk`. The run basenames, IDs, weights, checkpoint cadence, selected/latest aliases, configs, metrics and scientific evidence are preserved. The seven primary run directories remain in place. Run directories that are external symlinks are archived as links; their external payloads are not copied or relocated.

The root retains one additional `thermal_a2d_full5000` source alias because all three U configs and saved identities reference its exact original spelling. Its target is unchanged, and the same source is also discoverable in the A2D archive group. No U recipe, initialization identity, or protected run metadata is rewritten to accommodate the archive. The active compact scratch run remains in place and is not stopped, restarted, resumed or reconfigured by this work.

Only the three-epoch Run1699 smoke’s temporary weight aliases and training curves were removed: 21 file entries, 381,148,554 apparent bytes, corresponding to 191,150,760 unique inode bytes (191,172,608 allocated bytes). Root/checkpoint aliases were hardlinks, so apparent bytes are not disk savings. Its configs, manifests, metrics, numerical evaluation arrays and field/routing figures remain under the smoke-evidence group with an explicit cleanup marker. Zero-epoch failures cited by historical reports, short scientific negative controls and failed formal runs remain retained.

Frozen historical manifests, numerical summaries and checkpoint payloads retain their original path strings as provenance. Use the current location table below to locate relocated evidence. Maintained source readers and report links use the new archive paths. The local recursive inventory, dependency checks, selected-checkpoint hashes, rename/deletion allowlists and verification receipts are retained under `/data2/wanglz/ModularDT/thermal_run_archive_review_20261023/`; they are not uploaded.

Both candidates have context width 128, four heads, two staged cycles and a width 128 local reader. Coordinates remain in the native adapter frame. The shared core concatenates prescribed attributes with normalized coordinates, three fixed sin/cos frequency pairs and object/cell lengths divided by domain extent. Thermal supplies module radius, environment cell lengths `[Lx/24,Ly/8]` and separate local radius `3r`. Wind supplies rotor diameter, environment cell lengths `extent_D/4` and separate local radius `1.5D`; its native coordinates are already wind-aligned. Pair scale is the per-axis geometric mean of the two declared lengths. IDs preserve correspondence and never enter learned embeddings.

Every cycle reinjects raw token encodings and a learned scene summary through separate residual projections with live gates initialized to 0.1, then executes MM, EM using the updated M, EE using the updated E, and ME using the updated E, with one FFN per type. The scene summary combines separately measure-normalized M/E pools, prescribed operation, physical module count and separately typed mass/size information. Environment sample count is excluded. Route Q/K vectors are normalized per head; the live positive scale begins at `sqrt(head_width)` and stays in `[1,32]`. SDPA receives scaled Q and `scale=1.0`. Empty donor rows are exactly zero. Geometry descriptors are reused within one forward; changed donor states receive fresh learned projections.

`A2-H6` prepares six spatial contents through two shared-parameter edge-to-donor reads, separated by one H×H attention residual. Each typed gather W is normalized directly over eligible donors using physical measure and a bounded spatial prior. Final Thermal coefficients are `C[g,r,i]=W_M[g,i]*kappa[g,r,i]`, with no second measure factor. One nonlinear width 128 query-edge message is split into four width 32 feature heads with separate six-edge access. Each head supplies one signed Thermal spatial mode. The organized Thermal contraction computes `C h` before query expansion and retains factorized increments/JVP/VJP; explicit dense K is a bounded diagnostic. `A2-D` uses the same encoder/query/local capacities with direct physical-source information reads and independent signed Thermal source coefficients, without a cross-source softmax multiplier. Its direct coefficient arrays are an explicitly counted uncompressed reference. There is no dense source decoder in `A2-H6`.

Learned scene context may enter the content bank and C, but has no direct path into the organized receiver query or output head. Prescribed operating conditions may enter queries. Heating enters only the final affine contraction. Thermal has fresh u/v/p and temperature response heads, heat-independent flow and `T(0)=0`; omega, interpolation, material observations and q come from the maintained native extraction. Wind retains `height_profile(z)+normalized_residual*safe_std*u_ref`, without adding the absolute normalization mean or applying another rotation.

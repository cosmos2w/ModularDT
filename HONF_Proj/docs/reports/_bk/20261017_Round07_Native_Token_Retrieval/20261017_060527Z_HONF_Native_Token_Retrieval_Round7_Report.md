The implementation now includes live permission gradients, actual gathered nonlinear value execution, original-reader all-open recovery, strict continuation/loading support and an executable cost-admission gate. There are **zero new scientific continuation updates**, no e600/e1000/e1500/e2500 scientific child checkpoints, no optional E pilot, no full-TRAIN launch, no inverse run and no new solve.

The current retrieval candidate has no cost-admitted policy for the planned matched continuation and no complete native numerical qualification. ## Implemented mathematical and execution contracts

A native store retains module/environment IDs, coordinates, characteristic lengths, physical measures, validity, raw features, final contextualized states and available projections. A graph stores associations and permissions over those records; it contains no pooled decoder value, centroid, prototype, moment bank or new learned edge state. A contextualized native module record can contain information from other modules and E through the original preparation. Preserving its ID does not make its latent contents a pure local physical state.

For each captured raw-score row, density is `r = exp(L − max_allowed L)`, excluding log physical measure. Compact permission is the quintic `S5(clamp((r−tau)/tau, 0, 1))`; tau zero explicitly opens eligible routes. Query permissions reuse existing A2-D scores. Retrieval takes the maximum product over query-selected seeds and their native members, then the conservative union across heads. The unchanged compact local geometry window protects its original IDs before measure weighting. Equal maxima remain tied and IDs are never learned numeric features.

Information attention normalizes score, permission and physical measure. Thermal uses the separate signed physical sum `K_i = max_head(permission_i) * k_raw_i + K_local_i`; information attention is not inserted into that source sum. Heat does not select the graph, alter its contextual states or change flow. Native curl, interpolation, interface/q-proxy extraction, endpoint maxima and unit transforms remain with the original case adapters.

The selected executor gathers unique `(batch, query, module)` rows before Fourier features, SiLU values and message/scalar projection. Each original query-dependent value is shared across decoder heads. The dense-masked reference builds every rectangular Fourier/SiLU hidden row, then projects admitted rows; hidden and output-projection counts are recorded separately. Original full A2-D remains the complete application denominator. Thus a smaller dense-masked projection count is not reported as sparse hidden execution.

Prepared stores, graphs and plans reject changed owners, parameter/buffer versions, scene/frame/normalization/query identities, in-place tensor changes and reuse after backward consumption. Ordinary graph capture is opt-in and preserves existing SDPA and historical EM/EE behavior. The one bounded compiler repair fuses the same selected value formula for inference only; autograd and higher derivatives use eager execution. Compiler setup is charged separately, numerical misses are retained and no unqualified backend is recommended.

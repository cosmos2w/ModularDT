## Data, frozen sources, and scope

WindFarm targets are the existing stored, cell-centred OpenFOAM velocity fields in physical m/s, accessed through the native read-only mmap view. The new students begin from the intact Run 2110 W-full update-1500 checkpoint; Run 2110 W-packet update-1500 and Run 2103 epoch-2475 remain read-only historical comparisons. The source checkpoint and train/validation split are checked at launch, and the four previously used organizer-development layouts remain excluded from new student fitting. No new WindFarm CFD solve is part of this study.

ThermalChannel targets come from the documented local analytic-wake/shared-grid thermal generator and packed historical records. The intact Run 1804 epoch-4738 checkpoint is the forward source and Run 1502 epoch-4794 is a read-only comparator. Any new local reference attempts are reconciled against the standing 320-attempt ledger before launch, counted individually, and kept within its verified remaining allowance. The previously inspected Re90 response families remain development evidence.

The learned forward organization is input-only: it sees design geometry, operating context, current encoded states and the requested capacity vector. It does not see target fields, reconstruction errors, held inverse targets or inverse objectives at inference. A sparse result requires positive hard reductions in exact eligible receiver/source work while retaining measured role fidelity. A deployment full-access fallback is counted separately.

## Method and matched controls

For each dataset, G uses at most the top three levels of the native receiver tree, giving at most 26 complete cuts. A declared capacity is applied to QE and one training-pilot-selected consequential transport route. The budgets are 1.00, 0.90 and 0.75 of canonical weighted unique-pair work. Untargeted routes are explicit full-access bypasses. Hard physical values and physical gradients come from the native hard computation; a detached-physical soft shadow trains source permissions. Initial fitting samples root, intermediate and leaf cuts before a training-only table of measured cut outcomes supervises the input-only frontier utility head.

P has its own receiver/source scorer and exact per-receiver native access, trained on the same physical cases, query stream, capacity settings, physical initialization, trainable scope and update count. G's hard weights are also compared with its own root source union, geometry grouping, size/degree-matched rewiring and full access. These same-weight interventions test the current predictor's reliance on organized access; G versus P tests whether sharing access in packets adds value beyond competent direct selection.

Stage B labels are built on training cases only and report per-role reference RMSE, same-student full-access distortion, weighted canonical work and actual hard source support for each tested cut. Stage C predicts dimensionless role risk and work under a declared scaling rule. A cut is deployed only when predicted adequate under the declared role tolerance; otherwise an `unsupported_at_budget` result and the least-risk budget-feasible research cut are both retained. Hard K is an outcome, with no histogram or variance target.

The inverse pilots compare small, equally initialized denoisers using the same observations, noise streams, updates, sample count and frozen forward embeddings. The graph arm receives current-candidate typed hard permissions; the dense arm receives matched full-access links. The forward model and organizer are frozen before either inverse arm trains. Thermal generates nonnegative heat allocations with each task's supplied total at fixed geometry. Wind generates hidden turbine positions with visible positions fixed, then reports validity/rejection and stored-reference coverage. Sampling trails are trajectories of the sampler, not optimization-progress curves.

# HONF document chronology and archive audit

Archive review completed on 7 October 2026. This index records all 140 Markdown documents present under `docs/reports` and `UpgradePlan` before the review, plus one report-directory plan that was already absent. Research reports and plans receive sortable date prefixes; navigation indexes, reproduction commands, supporting findings and the current DeepGeoThermal quickstart retain stable names. Closed top-level research plans move to the existing `UpgradePlan/ThemalChannel` directory, and closed reports move to `docs/reports/_bk`. Existing historical thematic archives retain their locations.

Filename clocks are evidence labels, not invented experiment dates. A precisely declared proposal or completion clock would take priority; none was substantiated for the reviewed report closeouts. Report prefixes therefore use the earliest recorded Git addition commit time converted to UTC (`YYYYMMDD_HHMMSSZ`). Plans were previously entirely ignored and have no Git history: explicit proposal dates use `YYYYMMDD` without an invented clock; otherwise preserved filesystem birth times provide a clearly labelled file-creation fallback. File creation may reflect copying or migration and does not establish when work was proposed. Unknown proposal/completion dates stay unknown. For closed work whose exact completion date is absent, the table gives the last pre-archive Git publication of the closed report as a conservative upper bound, explicitly labelled; this is not a measured finish time.

Closed bounded work includes failed gates, stopped or resource-censored experiments and deliberately unexecuted follow-on branches; it does not mean every proposed experiment succeeded. Historical partial/handoff records and explicitly unexecuted plans retain those classifications. Root READMEs and supporting evidence catalogues remain navigation/reproduction documents. The preexisting missing R-Direct readiness plan is not restored or included in this commit.

Only durable Markdown in UpgradePlan is newly eligible for Git; numerical data, checkpoints, generated plots and other local artifacts remain excluded. Existing figure/data locations are unchanged. Relative links were rebased to keep their targets and uniquely resolvable legacy links were repaired. Remaining unavailable legacy targets are listed below.

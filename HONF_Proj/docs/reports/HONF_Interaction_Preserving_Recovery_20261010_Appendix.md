## Decision question and model contract

The experiment asks whether an explicit, shallow collective organization helps once a competent nonlinear, source-conditioned path is restored, while each Thermal model learns its flow and temperature fields jointly and Wind retains its shared nonlinear velocity core. J-direct is a pooled-context baseline, not the source-conditioned MM/ME/EM control required here.

The intended common path forms nonlinear message values from destination state, donor state, and signed relative geometry before reduction; it keeps source-source (MM), source-environment (ME), and environment-source (EM) reads, then reads individual physical sources nonlinearly at each receiver before source reduction. Physical source identities, native measures, self-exclusion, output laws, and complete smooth access remain explicit.

P is the fresh direct path. P-G adds one shallow collective residual with fixed smooth geometric memberships, and P-H uses the same collective width and prior with learned residual membership scores over that geometric start. P-G and P-H must begin from identical common-path tensors and identical zero-output collective projections, so the organized initial function recovers P exactly; all shared-core and output parameters remain trainable from the first update.

The collective block is an information residual inside one shared trainable model, not a second field network and not a correction to a frozen predictor. No frozen D-sep weights enter any new Thermal fit, no model is routed by case, and no support threshold forces small K.

Thermal physical inputs remain heat-independent: source geometry and heating are carried separately; one shared trainable core supports flow and temperature, and the temperature field preserves its native affine heating law and q-proxy role. Wind physical inputs retain rotor-relative source geometry, wind direction, and profile/context; the output remains a nonlinear residual on the fitted height profile in m/s.

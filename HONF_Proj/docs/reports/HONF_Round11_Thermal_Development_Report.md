# Round11: Thermal HONF development and full-TRAIN handoff

The shared HONF executor now reduces hidden values before output projection, offers segment and dense-weighted execution of the trained gates, and separates execution settings from the scientific model. An ordinary Thermal runner supports native training, resume, evaluation and assessment through the maintained TrainingEngine. Completed U checkpoints were evaluated rather than retrained. The optional E-access modification was skipped; the user's subsequent authorization adds one 200-epoch full-TRAIN H run on GPU0, whose startup is reported separately from completed scientific results.

## Executor evidence and numerical limits

Segment execution removes the old wide source-order reduction scratch, reduces nonlinear hidden values by destination/head and applies output projection with actual guarded mass. Thermal signed scalar composition preserves physical source gates without multiplying by information attention. Dense-weighted uses the same trained coefficients and physical law, charging all rectangular value rows. Historical source-order execution remains available. Pure value/tile checkpoint modes, tile size, context backend and aggregated telemetry are execution choices; state changes invalidate prepared graphs. Separate work-only routing derivatives remain because the maintained engine uses separate objective VJPs. Telemetry distinguishes reader scores, the additional pre-E M routing-score pass, and work-only replay; E routing scores are reused for its reader. These are forward algorithmic counts, not counts of every activation-checkpoint recomputation.

Independent FP64 explicit-sum and signed-source references pass. Actual M1/M12 native comparisons have maximum TRAIN-scale-normalized field RMS below 7.2e-6, global supervised-gradient relative L2 below 5.2e-5 and work-gradient difference below 9.5e-7. Some weak/cancelling per-parameter FP32 gradients exceed the initial 1e-4 relative expectation, including a 6.9e-4 gate gradient with absolute difference about 7.3e-9; those misses are not relabeled passes. With deterministic dense-weighted context, source-order repeats are bitwise equal and the first alternative-backend difference occurs in E reduction (at most 2.39e-7), with identical gates/alphas. One disposable AdamW update differs by relative L2 1.076e-4 for segment and 7.013e-5 for dense-weighted. CUDA segment context also introduces reduction nondeterminism. The old negative parity findings remain unchanged; segment remains an explicit experimental alternative where tighter update parity matters.

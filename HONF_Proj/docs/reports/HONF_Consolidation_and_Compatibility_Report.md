# HONF consolidation and compatibility report

This revision keeps six explicitly named model families, removes retired experiment dispatch from the maintained branch, simplifies the retained implementations without renaming saved state, and replaces the project README with a collaborator-oriented explanation and saved examples. The historical research source remains at `7981c173e8b1d29ee2b3addb7b972d0f15003542` on `cosmos2w/historical-honf-r13-20261029`; implementation lives on `cosmos2w/honf-consolidation-test` in an isolated DATA2 worktree. The historical branch is a retained milestone reference; server-side branch protection was not configured. Main was not merged or rewritten.

Existing serialized architecture identifiers, tensor keys, adapters and physical laws remain unchanged. The coarser historical case-plugin registry remains separate from this six-family catalogue.

Anchored S/X directly use their actual base implementation instead of inheriting through seven intermediate research variants; the three extracted numerical primitives match their historical definitions. Research task and evaluation dispatch retain anchored S/X, while the canonical U-H engine retains its original provider, schedule, optimizer, RNG, sampling, selection and history contracts. Shared implementation still used by these models remains in place, even where an internal module name reflects its historical origin. All 29 entries in the reduced managed-profile registry load successfully. Retired experimental plugin selectors reject unsupported workflows. Historical documentation links to removed source now reference the immutable milestone instead of dangling current-branch files. The [current guide index](../guides/README.md), [core contract](../../src/honf_forward_core/README.md) and [case integration guide](../case_plugin.md) distinguish current entry points from ancestry.

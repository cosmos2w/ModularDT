# Run 1507: task-trained functional coalescence

## Scope and evidence policy

Run 1507 is the single fresh 1503-v5 candidate on `agent/honf-core-next`. It retains the Run 1502 K=12, D=16 fine physical reader, source normalizers, task losses, seed 0, and fixed eleven-node tree. A shared phase-conditioned controller attenuates tree-Haar differences between the original access functions. The expected-class penalty is live during training and its inputs are detached from the source network. No online probe score chooses a merger, and no fine QM/QE physical-row sparsity is claimed from a smaller logical R.

The 90 HDF5 `test` IDs are **development cases** because this split also supplies sampled validation. Full-grid results and checkpoint selections must be labelled separately. Local one-time scripts, raw data, and generated figures are under ignored `diagnostics/generated/` paths; the maintained implementation and tests are in the repository.

## Why Run 1506 did not contract

Run 1506's passive node rule has zero score derivative when the observed squared discrepancy exceeds the keep threshold, and the task objective has no independent pressure to enter its transition band. The train-derived pair minimum was 0.203206, above the 0.06 keep scale; surveyed exact e500 and distinct selected checkpoints had R=12 and zero closed nodes. The score uses a maximum probe numerator divided by mean action energy, then maximizes over roles and blocks. It is a conservative action diagnostic, not a field-error guarantee.

A train-only panel of eight cases (two each with M=3/5/7/10) yielded 3,168 probe-role/block/node rows. The ratio of the worst-probe numerator to its weighted-mean counterpart had median 4.455, p90 8.449, p99 15.813, maximum 22.152. Forced exact full ties at three low-score nodes changed the selected fields by 1.3–4.4% relative and worsened the target fluid-field relative L2 by 0.0019–0.0072; port and flux changes were mixed. Thus even low-score distinctions were not uniformly harmless or uniformly damaging.

Using the same shared neural tensors, bounded direct-parent replays of Run 1506 e459/e500 changed selected outputs by about 1e-7 relative. A real e50-to-e51 update with matched Run 1502/1506 weights, optimizer, batch, and RNG found a field difference 3.6e-7 relative and loss difference 6e-8. The post-clipping update differed in 151 tensors, with maximum absolute difference 5.66e-7. This supports a changed floating-operation sequence in the inert wrapper; it does not explain the entire independently trained endpoint gap. These local checks are in `diagnostics/generated/run1506_causal_review/`.

## Scientific stop and recommendation

Stop Run 1507 at exact e150. The one fresh candidate has a functioning trainable pressure and an exact compact/virtual quotient, but the full-strength endpoint collapses every tested case and phase to the same R=1 class, while both selected checkpoints have zero effective mergers. Its aggregate field accuracy is worse than the matched parent on every development case; final port errors rise on average, and matched-chunk full-forward cost rises. The q-normal RMSE improvement on many cases is a genuine mixed physical result and is retained above. No native input-driven topology transition was found, so switch continuity cannot be certified. An e151–500 extension of this fixed recipe is not justified by the plan's adaptive-coalescence criterion, and a 5000-epoch run is not recommended. The scientific conclusion is limited to this recipe, fixed tree, dataset, and bounded native scan; it does not rule out task-trained detail retention with a different controlled design.

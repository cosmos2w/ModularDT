## Scientific acceptance and remaining measurements

Priority fluid/surface/material temperature and module-peak endpoint errors must each retain mean≤1.10 and p90≤1.15 of the same-age J-D; every other quantity, worst case and module-count regression remains visible. Module-peak endpoint is per-case RMSE of the errors between separately recomputed original-module maxima, not a maximum temperature sampled from another output. Existing-reference response reporting uses per-component absolute errors, relative errors only above fixed near-null floors, and descriptive median/p90 preservation bands against J-D. None is a physical validity or significance guarantee.
